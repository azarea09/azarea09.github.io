ダウンロード

1. コンソールアプリを作成する​

  1. Visual Studioを起動し、新しいプロジェクトの作成(N) を押します。
  2. コンソールアプリ を選択してプロジェクトを作成します、.NET 8で作成することをおすすめします。
  3. 作成時には、ソリューションとプロジェクトを同じディレクトリに配置する (D) のチェックを外してください。

2. Sharpをダウンロードし、配置する​

  1. このリンクからSharpをダウンロードして任意の場所に解凍します。
  2. 作成したプロジェクトのフォルダを開き、そこに解凍したSharpを配置します。

3. Visual Studio でプロジェクトを設定する​

  1. VisualStudioでプロジェクトを開きます。
  2. ソリューションを右クリックし、既存のプロジェクトの追加 を選択します。
  3. Sharp.csprojを選択して、プロジェクトを追加します。
    (画像のようになればOK)
  4. プロジェクトの依存関係を右クリック、プロジェクト参照の追加を選択しチェックして適応します。

3. サンプルプログラムを使う​

  1. 以下のサンプルプログラムを Program.cs にコピー＆ペーストし、ビルドして起動してみましょう。
  2. 正常に起動できれば導入は成功です。次の章では、Sharp の基本的な書き方について説明していきます。
Program.cs
using System.Numerics;
using SharpEngine;
using Raylib_cs;

class Program
{
    public static void Main()
    {
        Sharp.Init(
            beforeInit: () =>
            {
                Raylib.SetConfigFlags(ConfigFlags.ResizableWindow);
            },
            afterInit: () =>
            {
            },
            WindowSize: new Vector2(1280, 720),
            SceneSize: new Vector2(1920, 1080),
            WindowTitle: "Sharp Window"
        );

        while (!Raylib.WindowShouldClose())
        {
            Sharp.Loop(() =>
            {
                Raylib.ClearBackground(Color.RayWhite);
                Raylib.DrawText("FPS : " + Raylib.GetFPS(), 12, 12, 20, Color.Black);
            });
        }
    }
}
