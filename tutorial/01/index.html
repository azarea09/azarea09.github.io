1. Sharpの基本

Sharp プログラムの基本的な構成を学びます。

1.1 最小の Sharp プログラム​

以下は、FPS（フレームレート）を画面左上に表示するだけの最小構成のサンプルコードです。

  • Sharp を使うには、Sharp.Init と Sharp.Loop の2つの関数が必要です。
  • 各部分の説明は後ほど行います。
Program.cs
using SharpEngine;
using Raylib_cs;
using System.Numerics;

class Program
{
    public static void Main()
    {
        // Sharpの初期化
        Sharp.Init(
            beforeInit: () => {},
            afterInit: () => {},
            WindowSize: new Vector2(1280, 720),
            SceneSize: new Vector2(1920, 1080),
            WindowTitle: "Sharp Window"
        );

        // メインループ
        while (!Raylib.WindowShouldClose())
        {
            Sharp.Loop(() =>
            {
                Raylib.ClearBackground(Color.RayWhite);
                Raylib.DrawText("FPS : " + Raylib.GetFPS(), 12, 12, 20, Color.Black);
            });
        }
    }
}

1.2 using 宣言​

C#では、最初に using を書くことで必要なライブラリを使えるようになります。

  • SharpEngine を使うには using SharpEngine; を書きます。
  • Raylib_cs は SharpEngine の内部でも使われているため、併せて使います。
using SharpEngine;
using Raylib_cs;
using System.Numerics;

1.3 Init関数​

Sharp.Init は Sharp の初期化処理を行います。

  • WindowSize：表示ウィンドウのサイズ

  • SceneSize：ゲーム画面の内部解像度

  • WindowTitle：ウィンドウのタイトル

    Sharp.Init(
        beforeInit: () =>
        {
        },
        afterInit: () =>
        {
        },
        WindowSize: new Vector2(1280, 720),
        SceneSize: new Vector2(1920, 1080),
        WindowTitle: "Sharp Window"
    );

初期化の流れ​

  • beforeInit：ウィンドウ作成前に呼ばれます（主にRaylibの設定など）

  • afterInit：ウィンドウ作成後に呼ばれます（テクスチャや音声の読み込みはこちらで）

    Texture tex;
    Sharp.Init(
        beforeInit: () =>
        {
        },
        afterInit: () =>
        {
            // テクスチャの読み込みは afterInit 内で行う
            tex = new Texture("example\\test.png");
        },
        WindowSize: new Vector2(1280, 720),
        SceneSize: new Vector2(1920, 1080),
        WindowTitle: "Sharp Window"
    );
